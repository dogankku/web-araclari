# Yasal Gibi Web Araçları

50 adet “yasadışı gibi hissettiren ama yasal olan” web sitesini tek ekranda sunan modern React/Vite katalog projesi.

## Özellikler

- 50 web sitesi hazır veri dosyasıyla gelir
- Kategori filtresi
- Anlık arama
- Favorilere ekleme
- Responsive modern kart tasarımı
- GitHub Pages / Vercel / Netlify için uygundur

## Kurulum

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Veri Güncelleme

Siteler `src/tools.js` dosyasında tutulur. Yeni site eklemek için aynı yapıda yeni obje eklemeniz yeterlidir.

## Önemli Not

Bu proje yalnızca katalog amaçlıdır. Listelenen sitelerin kullanım şartları, telif kuralları ve yerel yasalar kullanıcı sorumluluğundadır. Özellikle akademik yayın, kitap ve medya indirme sitelerinde telif durumunu kontrol etmeniz gerekir.
